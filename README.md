# 雜阿含 62 經 ·【五受陰 · 見我與不見我】HTML 教學簡報

佛住舍衛國祇樹給孤獨園，告諸比丘：愚癡凡夫無慧無明，於五受陰**見是我、異我、相在**，繫著、使、心結縛而生貪欲；
多聞聖弟子有慧有明，不見我，正觀色受想行識**皆悉無常**。
